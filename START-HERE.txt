NOTES
--------------------------------------------------------------------
All class data is synthetic. No real child was involved at any point.

Detection is deterministic arithmetic running in the browser — five
fixed rules, no model involved in deciding which child is flagged.
Generative AI writes only the suggested wording a teacher reads.
Full details in AI-TOOLS-DECLARATION.pdf.

server.js powers the optional live multi-device demo and needs
Node.js plus "npm install" — see DEPLOY.md. It is not required to
review the project; index.html alone is the complete prototype.
